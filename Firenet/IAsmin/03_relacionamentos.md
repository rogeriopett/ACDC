# Relacionamentos (chaves estrangeiras) — banco Firebird

Contexto para IA. Ligações entre tabelas para montar JOINs, extraídas do metadata (`DDL_Banco.sql`). Tipos e demais colunas em `02_dicionario.md`.

## Como ler

- `COLUNA → TABELA_REF.COLUNA_REF`: o valor de `COLUNA` é o código de um registro em `TABELA_REF`.
- JOIN correspondente: `... FROM VENDAS V JOIN CLIENTES C ON C.CLI_CODIGO = V.VED_CLIENTE`.
- `[cascade]`: apagar o registro referenciado apaga também os registros desta tabela (ON DELETE CASCADE). `[set null]`: a coluna vira NULL. Sem marca: o banco impede apagar o referenciado enquanto houver vínculo.
- Quando a coluna aceita NULL, use `LEFT JOIN` para não perder registros sem vínculo.
- Colunas que não aparecem aqui não têm chave estrangeira declarada, mesmo que o nome sugira (ex.: `_USUARIO` é VARCHAR com o login, não código).
